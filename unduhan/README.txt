FOLDER BERKAS UNDUHAN
=====================
Taruh file dokumen/formulir (PDF, DOCX, XLSX, dll) di folder ini, lalu isi "Tautan / path berkas"
di admin.html > menu Unduhan dengan path-nya, contoh:

    unduhan/formulir-pkl.pdf

Tips:
- Pakai nama file huruf kecil tanpa spasi (formulir-pkl.pdf), bukan "Formulir PKL (1).pdf".
- Alternatif tanpa upload ke hosting: tempel link Google Drive (Bagikan > "Siapa saja yang memiliki link").
  Link Drive otomatis diubah menjadi unduhan langsung.
